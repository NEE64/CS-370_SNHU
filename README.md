# CS-370_SNHU
This is my private repository for the course CS-370 at SNHU.

Computer scientists help solve some of humanity’s biggest modern problems by designing and developing various computational systems. This work is important because it shapes how we live on a daily basis, from improving diagnostic medicine to driving innovations in business. During this course, I examined the many (potential) uses of artificial intelligence (AI) in the business, gaming, and health sectors. I also completed projects that required me to optimize algorithms.
